# 三分钟演示路线

打开 http://127.0.0.1:4348 。默认展示已完成的真实商品Demo。

1. **商品洞察**：查看46 USD商品、100条评论，以及仅6条对应当前SKU的说明；点击来源验证。
2. **Round 01 → 内容矩阵**：13种角度、4种人设，每格对应真实脚本，不是计数占位。
3. **Top20 → 任意脚本**：展示前三秒、完整口播、逐秒画面、B-roll、道具和七维评分。切换“准备拍摄”。
4. **素材工厂**：分配负责人、登记素材链接与使用权；导出Shot List给拍摄团队。
5. **数据复盘**：显式指出这是模拟GMV样本。展示留存、CTR、CVR、ROAS、千次播放GMV与Content DNA。强调相关性与小样本限制。
6. **Round 02**：100条新方案，创作方向依据模拟复盘重新分配；本次标准案例中宝妈人设由25条增至48条。具体数值以该次运行记录为准，两轮不重复完整组合。
7. 输入 **“只做15秒UGC”**：生成20条4镜头方案。再输入 **“把Top10改成宝妈人设”**：生成保留父脚本关系的改写批次。
8. 导出Top20 Markdown或整批JSON，交付实际拍摄。

若要重新走链接起点：点“新建商品”，使用README中的真实商品URL；或在终端执行 `npm run demo -- --live` 自动走完整两轮。若网站暂不可达，使用明确标记抓取时间的本地快照Demo，不伪称重新抓取成功。

标准案例入口：`http://127.0.0.1:4348/case-assets/`。正式讲解先打开“增长工作流”，再按 [演示与内容素材](case-assets/演示与内容素材.md) 中的路线展示。
